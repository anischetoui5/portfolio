Featured project

EASYfact

AI-powered invoice & expense management platform

Final Year Project · 2026

A multi-tenant SaaS platform that streamlines invoice and expense management for businesses through automation, OCR and AI-powered assistance, built to cut manual data entry and make financial operations simpler.

  • OCR invoice extraction with Tesseract.js, supporting French and English documents.
  • AI assistant powered by the Groq API (Llama 3.3 70B) for help with invoices and financial data.
  • Multi-tenant architecture supporting multiple companies and workspaces.
  • Role-based access for Directors, Accountants and Employees, with workspace-level permissions.
  • Real-time updates and chat with Socket.IO.
  • Interactive dashboards, expense tracking and invoice management.
  • Subscription-based access management.
  • Customizable interface for each user.
  • React
  • TypeScript
  • Node.js
  • Express.js
  • PostgreSQL
  • Socket.IO
  • Tesseract.js
  • Groq API
  • REST APIs
